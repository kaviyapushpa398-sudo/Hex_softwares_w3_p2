# Hex_softwares_w3_p2
📦 Inventory Management System (Java)

📌 Overview

The Inventory Management System is a Java-based application designed to manage products and track inventory transactions efficiently. It helps maintain accurate stock records, monitor inventory levels, and streamline operations in an organized manner.

This project was developed during my Java Programming Internship at Hex Software, focusing on building practical, real-world applications using core Java concepts.

---

🎯 Features

- 📦 Product management (add, update, delete)
- 🔄 Transaction handling (stock in / stock out)
- 📊 Real-time inventory tracking
- 👤 Simple and user-friendly interface
- 📁 Organized data storage and management

---

🛠️ Technologies Used

- Programming Language: Java
- Concepts Used: OOP (Object-Oriented Programming), Collections, Exception Handling
- (Optional) Database: MySQL / JDBC
- (Optional) UI: Java Swing / Console-based Interface

---

⚙️ How It Works

1. User adds and manages product details
2. Inventory transactions (stock in and stock out) are recorded
3. System automatically updates stock levels
4. Users can view inventory status in real time
5. All data is stored for future reference

---

▶️ How to Run

1. Clone the repository
2. Open the project in any Java IDE (Eclipse / IntelliJ IDEA / VS Code)
3. Compile and run the main class
4. Follow on-screen instructions to use the system
